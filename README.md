# Adil Ahmed

System architect and founder of [Start Daily xyz Limited](https://startdaily.xyz), a custom software and AI automation studio in Dhaka.

I design and build the systems organisations run on: ERPs, healthcare and education platforms, CRMs, internal portals and automation. The work starts with how the business actually operates, and ends with software the client owns and can run without me.

Start Daily also builds its own products: **StartOS**, **Mediculum OS**, **StudyAbroad OS** and **E/Q Commerce OS**.

## Core stack

TypeScript, Next.js, React, Node.js, Postgres (Supabase), Fastify, Flutter, React Native (Expo), S3-compatible storage, Vercel, Cloudflare, LLM APIs for automation.

## How I work

- **Architecture first.** Data model, roles and flows are agreed before screens are built.
- **Ownership.** One accountable lead from discovery to launch.
- **Handover.** Clients receive the code, documentation and access needed to run the system independently.
